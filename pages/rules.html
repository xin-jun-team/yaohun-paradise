遊戲規章

江湖有律，方能久安。以下守則為全體曜魂子民共同遵循之綱紀，入服即視為知悉並同意。守規者同樂，違律者受懲，望諸君共維一方淨土。

⚠️
加入曜魂天堂即代表您已完整閱讀並同意以下規章。管理團隊保有最終裁決權，所有判決均依現行規章執行，無法以「不知情」為由申訴。規章如有異動，將於公告欄發布，請定期確認。
言一、言論與行為規範
  • 禁止辱罵、騷擾任何玩家或管理人員，包含公開頻道、密語及血盟頻道。（警告／封號 3 天／三犯永封）
  • 禁止冒充 GM 或管理人員，以任何方式混淆身份。（永久封號並封 IP）
  • 禁止在任何公開頻道宣傳其他私服，一經發現立即處理。（永久封號並封 IP）
  • 禁止公開頻道洗版（重複傳送相同訊息），視情況給予警告或禁言。（警告／禁言 3 天）
  • 禁止使用含有歧視、色情、政治或不雅意涵的角色名稱，GM 有權強制改名。
  • 玩家紛爭 GM 不介入，合乎規定的遊戲行為（PK、競爭、搶怪）均屬正常遊玩範疇。
掛二、外掛程式與系統漏洞
  • 禁止使用任何未經官方授權的第三方程式（含加速器、自動釣魚、連打軟體等）。（永久封號）
  • 發現系統漏洞（BUG）必須立即回報 GM，禁止重複利用或告知他人，隱匿並利用者視同外掛使用。（永久封號）
  • 接收並使用因漏洞產生的異常物品或金幣，即使非主動取得，亦連帶受罰。（封號 7 天／二犯永封）
  • 禁止使用任何方式入侵、修改遊戲封包或資料庫，此行為視為駭客攻擊。（永久封號並封 IP）
詐三、詐欺行為與現金交易
  • 禁止以任何方式詐欺其他玩家，包含虛假交易、欺騙轉帳、冒充人員索取裝備。（永久封號）
  • 現金買賣帳號、虛擬物品或遊戲幣，私人交易風險自負，官方不協助調查。
  • 盜竊帳號者，及接收贓物的共犯，一併受到處置，所有涉案物品由 GM 無償回收。（永久封號並封 IP）
  • 玩家交易風險自負，GM 不提供交易調解或物品找回服務，建議交易時使用遊戲內交易窗口。
平四、破壞遊戲公平性
  • 禁止惡意阻擋玩家移動、傳送、或佔用刷怪點，視情節輕重給予處置。（警告／封號 7 天）
  • 禁止公開散播其他玩家的個人資訊（真實姓名、聯絡方式、照片等）。（封號 7 天／二犯永封）
◆ 違規懲處速查
表違規懲處速查表
  • 辱罵玩家／洗版：警告 → 封號 3 天 → 永久封號
  • 冒充 GM／宣傳他服：永久封號 → 封 IP
  • 使用外掛程式：永久封號 → 封 IP
  • 利用遊戲漏洞：封號 7 天 → 永久封號 → 封 IP
  • 詐欺／盜號：永久封號 → 封 IP
  • 現金買賣帳號／物品：封號 3 天 → 永久封號
  • 惡意阻擋玩家：警告 → 封號 7 天 → 永久封號
  • 散播個人資料：封號 7 天 → 永久封號 → 封 IP
補五、裝備誤刪補救機制
  • 補救服務僅限誤刪，主動銷毀、交易後悔、賭輸不算；每帳號每月申請上限 2 次。
  • 所有補救裝備一律還原為 +0 無附魔 狀態，強化值、附魔效果不予補回。
  • 誤刪補救費用（藍鑽）：英雄級 1,000／傳說級 3,000／神話級 5,000，聯絡 GM 處理。費用可能因版本調整，以 GM 公告為準。
  • 衝爆贖回費用（新台幣）：英雄級 NT$ 1,000／傳說級 NT$ 3,000／神話級 NT$ 5,000，僅受理強化失敗爆裂情形，付款方式洽 GM 確認。
訴六、申訴與帳號管理
  • 若認為判決有誤，請透過官方 LINE 社群或聯絡我們頁面提交申訴，需附上截圖或錄影佐證。
  • 申訴期限為封號起 7 天內，逾期不予受理；永久封號且 IP 封鎖者不得申訴。
  • 帳號超過 30 天未登入者，系統將自動刪除。
  • 帳號由本人負責保管，帳號外借、共用所產生的一切後果由帳號持有者承擔。
⚖️
曜魂天堂管理團隊保有對所有規章的最終解釋權與裁量權。本規章旨在維護公平健康的遊戲環境，管理團隊由 GM 志願組成，非職業性質。如對規章有疑問，歡迎至官方社群提問；凡惡意挑戰規章底線、試圖鑽空子者，管理團隊將以破壞遊戲環境論處。
